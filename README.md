# Canal de actualizaciones de Centrax

Este repositorio solo distribuye **actualizaciones compiladas** de
[Centrax](https://centrax.cl), el punto de venta para almacenes, minimarkets y
botillerías de Chile.

- No contiene código fuente.
- Los zips **no contienen credenciales de ningún tipo**: cada instalación conserva su
  propia configuración local al actualizarse.
- Los archivos `almacen.json`, `botilleria.json` y `producto.json` son los manifiestos
  que cada instalación consulta para saber si hay una versión nueva.

Para adquirir Centrax o pedir soporte: **contacto@centrax.cl**
